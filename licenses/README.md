# Licenses and third-party notices

This folder is copied into the published PhotoViewer folder. It is part of the binary distribution, not just developer documentation.

Contents:

- `GPL-3.0.txt` and `LGPL-3.0.txt`: verbatim GNU license texts required when conveying LGPL-3.0 components.
- `THIRD-PARTY-NOTICES.txt`: component, copyright, license, and bundled-file index.
- `SOURCE-OFFER.txt`: written offer for the Corresponding Source of the LGPL components.
- `LIBHEIF-BUILD-INFO.md`: exact upstream versions, commits, build information, and binary hashes.
- `RELINKING.md`: instructions for replacing the LGPL shared libraries.
- `third-party/`: upstream license/copyright texts for bundled third-party components.
- `dotnet/`: .NET 9.0.23 runtime license and third-party notices.
- `source/`: local source archives for the LGPL components, included as a convenience alongside the written source offer.
- `package-metadata/`: exact NuGet package files, nuspec metadata, README files, and MSBuild targets used by the build.

PhotoViewer's own application code remains MIT licensed; see `LICENSE` in the repository root or in the published folder. These notices do not change that license.
